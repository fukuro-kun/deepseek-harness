# Mitwirken

[English](CONTRIBUTING.md) | [中文](CONTRIBUTING.zh.md) | Deutsch

Vielen Dank für Ihr Interesse an einer Mitarbeit an DeepSeek Harness!

Wir glauben zutiefst an die Kraft von Open-Source-Communities, und diese Überzeugung prägt dieses Projekt von Anfang an.

DeepSeek Harness befindet sich noch in einem frühen Stadium und wird aktiv weiterentwickelt. Es tut uns leid, dass wir derzeit keine externen Pull Requests annehmen können. Code in dieses Repository beizutragen ist jedoch bei Weitem nicht der einzige Weg, zu helfen. Es gibt viele andere Möglichkeiten, mitzuwirken:

- Identifizieren Sie Probleme oder Fehler und melden Sie sie in den GitHub Discussions:
  - Stimmen Sie Diskussionen zu, auf die Sie die Aufmerksamkeit des Teams lenken möchten. Wir sind ein sehr kleines Team und können nicht auf jeden Beitrag antworten, aber wir beobachten sie und berücksichtigen sie bei der Ressourcenverteilung.
- Tragen Sie zum Ökosystem bei:
  - Erstellen Sie ein Plugin, das Sie begeistert, und teilen Sie es mit anderen:
    - Verknüpfen Sie Ihr GitHub-Projekt mit dem Thema `dsh-plugin`, damit andere Ihr Plugin leichter finden.
  - Schreiben Sie Blogartikel und Anleitungen über DeepSeek Harness.
  - Beantworten Sie Fragen und helfen Sie anderen Mitgliedern der Community.

DeepSeek Harness ist dafür konzipiert, tiefgreifend anpassbar zu sein. Wir glauben nicht, dass Pakete im offiziellen Repository von sich aus wichtiger sind als von der Community erstellte Pakete. Betrachten Sie dieses Repository gerne als Idee, offizielle Referenzanwendung und Quelle der Inspiration — aber nicht als Verpflichtung unsererseits.

Wir haben bereits faszinierende Projekte aus der Community hervorgehen sehen und hoffen, dass das Ökosystem in seine eigenen Richtungen weiterwachsen wird.

Ins Ungewisse.
